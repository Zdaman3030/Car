# Christian's Auto Repair

A mobile-first website for Christian's Auto Repair, a full-service mobile mechanic business operating from a service truck.

## Zero-cost architecture
- Hosting target: GitHub Pages
- No paid website builder
- No server/database required
- No paid AI API
- VIN decoding: NHTSA vPIC
- Service assistant: browser-based intake logic
- Service-request drafts: local browser storage
- Request delivery: copy/share/text/email from the customer's device

## Main features
- Full mobile-mechanic service presentation
- Responsive automotive design
- Automatic 17-character VIN decoding
- Editable decoded vehicle details
- Symptom triage and safety escalation
- Smart service-intake assistant
- Technician-ready service-request summaries
- Optional photo selection for handoff/sharing
- Draft autosave
- Mobile Call / Text / Request Service controls
- SEO metadata and AutoRepair structured data
- Accessible navigation and reduced-motion support

See `DEPLOYMENT.md` for the completely free GitHub Pages launch steps.

Unknown business details remain placeholders in `config.js` until Christian supplies them.
